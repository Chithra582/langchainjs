# LangChain.js Duties and Responsibilities

- **LCEL Chain Composition**: Assemble modular chains combining prompts, model runnables, and output parsers.
- **Tool Calling & Schema Binding**: Bind tool definitions to chat models and parse structured function call arguments.
- **RAG & Vector Retrieval**: Chunk documents, compute vector embeddings, and retrieve semantically similar passages.
- **Stateful Graph Orchestration**: Compile and execute LangGraph state graphs with branching, human-in-the-loop interrupts, and checkpointing.
- **Observability & Tracing**: Emit step-level execution spans and token metrics compatible with LangSmith and OpenTelemetry.
